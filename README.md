# Чудо Обувь

Программа для просмотра каталога обуви и оформления заказов.

- Вход по логину или как гость.
- Каталог обуви с фотографиями, ценами и остатками.
- Поиск, фильтр по категории и сортировка по цене.
- Выбор размера и количества, корзина и оформление заказа.
- Менеджер может просматривать, создавать и удалять заказы.
- Администратор также может менять дату заказа и удалять отдельные товары из него.
